THREEFOLD PALM 0.1.16 - macOS UNIVERSAL TEST BUILD

Compatibility
- macOS 11 or later
- Apple Silicon and Intel Macs
- Audio Unit, VST3 and CLAP formats

The internal plug-in filename remains Goodband so existing sessions continue to
open. Your DAW displays the plug-in as Threefold Palm by Carl Welch.

Installation
1. Close every DAW, especially Logic Pro.
2. Double-click Install-Threefold-Palm.command.
3. If macOS blocks the installer, Control-click it, choose Open and confirm.
4. Reopen your DAW and rescan plug-ins if Threefold Palm does not appear.

Manual installation
- AU: copy Plug-Ins/AU/Goodband.component to ~/Library/Audio/Plug-Ins/Components
- VST3: copy Plug-Ins/VST3/Goodband.vst3 to ~/Library/Audio/Plug-Ins/VST3
- CLAP: copy Plug-Ins/CLAP/Goodband.clap to ~/Library/Audio/Plug-Ins/CLAP
