THREEFOLD PALM 0.1.16 - WINDOWS x64 TEST BUILD

Formats
- VST3: Goodband.vst3
- CLAP: Goodband.clap

The internal filename remains Goodband for compatibility with existing sessions.
Your DAW should display the plugin as Threefold Palm by Carl Welch.

Installation
1. Close every DAW.
2. Right-click Install-Threefold-Palm.ps1 and choose Run with PowerShell.
3. Reopen your DAW and rescan plugins if Threefold Palm does not appear.

Manual installation
- Copy Goodband.vst3 to:
  %LOCALAPPDATA%\Programs\Common\VST3
- Copy Goodband.clap to:
  %LOCALAPPDATA%\Programs\Common\CLAP

Important
- This is an unsigned, pre-release test build. Windows or security software may warn about it.
- The build is for 64-bit Intel/AMD Windows systems.
- Do not distribute it beyond the invited test group.
