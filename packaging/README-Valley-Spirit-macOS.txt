VALLEY SPIRIT 0.1.5 - macOS APPLE SILICON TEST BUILD

Compatibility
- macOS 11 or later
- Apple Silicon Macs
- Audio Unit, VST3 and CLAP formats

The internal plug-in filename remains PitchTrails so existing sessions continue
to open. Your DAW displays the plug-in as Valley Spirit by Carl Welch.

Installation
1. Close every DAW, especially Logic Pro.
2. Double-click Install-Valley-Spirit.command.
3. If macOS blocks the installer, Control-click it, choose Open and confirm.
4. Reopen your DAW and rescan plug-ins if Valley Spirit does not appear.

Manual installation
- AU: copy Plug-Ins/AU/PitchTrails.component to ~/Library/Audio/Plug-Ins/Components
- VST3: copy Plug-Ins/VST3/PitchTrails.vst3 to ~/Library/Audio/Plug-Ins/VST3
- CLAP: copy Plug-Ins/CLAP/PitchTrails.clap to ~/Library/Audio/Plug-Ins/CLAP
