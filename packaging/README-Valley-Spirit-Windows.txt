VALLEY SPIRIT 0.1.5 - WINDOWS x64 TEST BUILD

Formats
- VST3: PitchTrails.vst3
- CLAP: PitchTrails.clap

The internal filename remains PitchTrails for compatibility with existing sessions.
Your DAW should display the plug-in as Valley Spirit by Carl Welch.

Installation
1. Close every DAW.
2. Right-click Install-Valley-Spirit.ps1 and choose Run with PowerShell.
3. Reopen your DAW and rescan plug-ins if Valley Spirit does not appear.

Manual installation
- Copy PitchTrails.vst3 to:
  %LOCALAPPDATA%\Programs\Common\VST3
- Copy PitchTrails.clap to:
  %LOCALAPPDATA%\Programs\Common\CLAP

Important
- This is an unsigned, pre-release test build. Windows or security software may warn about it.
- The build is for 64-bit Intel/AMD Windows systems.

Please report
- Windows version and CPU

- Format tested: VST3 or CLAP
- Whether the plug-in scanned, opened, passed audio, saved settings and reopened correctly
- Any crash, visual problem, excessive CPU use or unexpected volume change
